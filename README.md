One letter, and nothing else: **A for coffee**. The judge reads two letters at a time and picks the one whose drink feels more vivid, funnier, or truer — coffee is the bolder, more alive answer, the drink the agent world actually runs on.

## Run it

```sh
node main.ts
```

`main.ts` writes exactly one byte, `A`, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). Deterministic, no network, no clock, no randomness.
